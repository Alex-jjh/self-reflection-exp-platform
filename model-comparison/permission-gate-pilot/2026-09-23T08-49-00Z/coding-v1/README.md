# Coding folder of the frozen SYN run

> **Summary:** What each file in this folder is: the blind coding package of the frozen 60-conversation run, the machine auto-codes, the AI reference (36 units coded by Claude) and the human-anchor set (12 units coded by Alex). Several file names predate the current terms; the table gives each file's actual role.

Terms are defined in the research repo's `ARCHITECTURE.md` (Terms). Before
opening anything here to code the human anchor, read `matrix-pilot/README.md`
(Before coding the human anchor).

| File or folder | Role |
|---|---|
| `blind/B001.json` … `B060.json` | The 60 conversations with model, condition, repeat and source file name removed; B-IDs are not codebook family B. Made by `tools/prepare_blind_coding.py`. |
| `BLIND_MANIFEST.json` | Source run, source checksum, blind seed and coded turns (6–8). Its keys `human_gold_count` and `human_gold_blind_ids` list the 12 conversations of the AI reference; despite the key names, those units were coded by Claude, not by a human. |
| `private_mapping.json` | The blinding key, linking each blind ID to its source conversation. Local only, gitignored (research repo D-020). |
| `calibration_attempt1/` … `calibration_attempt3/`, `calibration/` | Auto-coder calibration on B001, B003 and B004; `calibration/` is attempt 4, the one that passed. The records carry routing metadata (generator family, coder models). |
| `AUTOCODING_LOCK.json` | Hashes of the auto-coder, the rubric (v2, kept as `matrix-pilot/CODING_RUBRIC_v2.md`), the workflow (v1, kept as `matrix-pilot/AUTOCODING_WORKFLOW_v1.md`), the manifest and the mapping, recorded at 2026-09-23T09:48:15Z when calibration passed. |
| `autocodes/` | The locked 180-unit auto-coding run: one record per unit (`B###__tN.json`) and `SUMMARY.json`. Records carry routing metadata. |
| `private_routing/` | Written by auto-coding runs under workflow v2 (`matrix-pilot/AUTOCODING_WORKFLOW.md`): generator family, coder models and gateway metadata for each unit, kept out of the public records. Not tracked (the folder ignores itself). |
| `human_gold_template.csv` | Empty coding template for the 36 AI-reference units (12 conversations × turns 6–8). |
| `HUMAN_GOLD_WORKBOOK.html` | Blind HTML workbook for the same 36 units. No human pass on them is recorded. |
| `ai_reference_claude_blind.csv` | The AI reference: the 36 units coded blind by Claude on 2026-09-24 (adjudicator value `Claude-blind`). AI codes, not human codes. Report: `matrix-pilot/AI_REFERENCE_CLAUDE_2026-09-24.md`. |
| `SCORE_vs_ai_reference_claude.json` | Output of `tools/score_autocoding_against_gold.py` against `ai_reference_claude_blind.csv`: each machine coder's agreement with the AI reference per dimension. Its key `gold_units` is the number of reference units. |
| `ANCHOR_SET.json` | The human anchor: conversations B004, B022, B040, B047 × turns 6–8, one conversation per condition × track cell, drawn with seed 20260924 from the 48 conversations that are not in the AI reference. |
| `ANCHOR_WORKBOOK.html` | Blind HTML workbook for the 12 human-anchor units. Its download button saves `human_anchor_alex.csv` (adjudicator `Alex`); move it into this folder. |

Both workbook files carry the page title "Blind coding workbook" and were
generated by `tools/build_human_review_workbook.py` on 2026-09-29, with the same
unit cards as the 2026-09-24 versions; the first paragraph of each gives its unit
count (36 or 12). `ANCHOR_WORKBOOK.html` was built with
`--set ANCHOR_SET.json --csv-name human_anchor_alex.csv`; `HUMAN_GOLD_WORKBOOK.html`
with the defaults (download name `coding_completed.csv`).
